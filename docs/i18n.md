# i18n 구현 완전 가이드

## 1. 프로젝트 개요

### 1.1 목표

- 한국어/영어/중국어/일본어 다국어 지원
- 사용자 브라우저 설정에 따른 자동 언어 감지
- 수동 언어 선택 및 localStorage 저장
- 모든 UI 텍스트 번역 (동적 데이터 제외)
- 날짜/시간 형식을 현지화

### 1.2 기술 스택

- **i18next** (^25.8.0): 핵심 i18n 프레임워크
- **react-i18next** (^16.5.3): React 통합 (useTranslation 훅)
- **i18next-browser-languagedetector** (^8.2.0): 브라우저 언어 감지
- **Intl API**: 브라우저 내장 날짜/숫자 형식화
- **localStorage**: 사용자 언어 설정 저장
- **Playwright** (테스트): E2E 자동화 테스트

### 1.3 번역 구조

```
FE/src/i18n/
├── config.ts                 # i18next 설정
├── alerts.ts                 # 번역된 alert/confirm 함수
├── locales/
│   ├── ko/                   # 한국어 (기준 언어)
│   ├── en/                   # 영어
│   ├── ch/                   # 중국어 (간체)
│   └── ja/                   # 일본어
│       ├── common.json       # 버튼, 폼, 공통 텍스트 (68+ 키)
│       ├── components.json   # 컴포넌트별 텍스트 (30+ 키)
│       ├── pages.json        # 페이지별 텍스트 (60+ 키)
│       └── utils.json        # 날짜/시간 형식 (20+ 키)
└── contexts/
    └── LocaleContextProvider.tsx  # 로케일 상태 관리
```

## 2. 논의 단계

### 2.1 요구사항 분석

| 항목             | 결정 사항                                    |
| ---------------- | -------------------------------------------- |
| **지원 언어**    | 한국어(ko), 영어(en), 중국어(ch), 일본어(ja) |
| **기본 언어**    | 브라우저 감지 → 한국어/영어 폴백             |
| **언어 선택**    | UI의 LanguageSelector 컴포넌트 제공          |
| **저장 방식**    | localStorage (key: 'locale')                 |
| **네임스페이스** | common, components, pages, utils (4가지)     |
| **날짜 형식**    | Intl.DateTimeFormat 사용                     |
| **동적 데이터**  | 이름/주소는 번역하지 않음                    |

### 2.2 아키텍처 결정사항

```
사용자 접근
    ↓
[LanguageSelector UI] ←→ [LocaleContext 상태]
    ↓                          ↓
[localStorage]         [i18n 인스턴스]
                              ↓
                    [각 컴포넌트의 useTranslation()]
```

### 2.3 구현 전략

- **점진적 통합**: 1개 Phase씩 완성 후 테스트
- **병렬 처리**: 여러 파일 동시 수정
- **재사용성**: 번역 키는 점(.) 표기법으로 계층화
- **에러 처리**: 누락된 키는 자동으로 경고 표시

### Phase 3: Alert/Confirm 래퍼 함수

#### 3.1 [FE/src/i18n/alerts.ts](FE/src/i18n/alerts.ts) 생성

```typescript
export const alertT = (key: string, params?: Record<string, any>) => {
  const message = i18n.t(key, params);
  alert(message);
};

export const confirmT = (key: string, params?: Record<string, any>) => {
  const message = i18n.t(key, params);
  return confirm(message);
};
```

#### 3.2 사용 예시

```typescript
// 기존
alert("저장되었습니다");

// 변경 후
alertT("components.alert.success.save");
```

**결과**: 모든 alert/confirm이 다국어 지원

```typescript
// formatToLocalTime.ts
export const formatToLocalTime = (date: Date, locale: string) => {
  return new Intl.DateTimeFormat(locale, {
    year: "numeric",
    month: "2-digit",
    day: "2-digit",
    hour: "2-digit",
    minute: "2-digit",
  }).format(date);
};
```

## 5. 사용 가이드

### 5.1 컴포넌트에서 번역 사용

```typescript
import { useTranslation } from 'react-i18next';

export function MyComponent() {
  const { t } = useTranslation(['common', 'components']);

  return (
    <div>
      <button>{t('button.confirm')}</button>
      <input placeholder={t('form.name.placeholder')} />
    </div>
  );
}
```

### 5.2 Alert/Confirm 사용

```typescript
import { alertT, confirmT } from "@/i18n/alerts";

// Alert
alertT("components.alert.success.save");

// Confirm
if (confirmT("components.alert.confirm.delete")) {
  deleteItem();
}

// 파라미터 전달
alertT("utils.dday.remaining", { days: 5 });
// "5일 남음"
```

### 5.3 날짜 포맷팅

```typescript
import { formatToLocalTime } from '@/utils/formatToLocalTime';
import { useContext } from 'react';
import { LocaleContext } from '@/contexts/LocaleContext';

export function DateDisplay({ date }: { date: Date }) {
  const localeContext = useContext(LocaleContext);
  const locale = localeContext?.locale || 'ko';

  return <span>{formatToLocalTime(date, locale)}</span>;
}
```

### 5.4 새 번역 키 추가

2. 컴포넌트에서 사용

## 6. 트러블슈팅

| 문제                        | 원인                       | 해결책                                 |
| --------------------------- | -------------------------- | -------------------------------------- |
| 번역이 표시되지 않음        | 키가 없거나 잘못됨         | i18n 콘솔 경고 확인, 네임스페이스 확인 |

| localStorage 저장 안 됨     | LocaleContextProvider 없음 | main.tsx에 Provider 감싸기             |
| 날짜 형식 이상함            | locale 파라미터 누락       | formatToLocalTime에 locale 전달        |
| 테스트 실패                 | Playwright 설치 안 됨      | `npx playwright install` 실행          |

## 7. 성능 최적화

### 7.1 번역 리소스 로딩

- 각 언어별 4개 네임스페이스로 분리 (Code splitting 가능)

- useTranslation 훅이 필요한 컴포넌트에서만 사용

- i18n 라이브러리: ~25KB (gzipped)
- 16개 번역 파일: ~150KB (압축 시 ~30KB)
